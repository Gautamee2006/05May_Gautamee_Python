1.  Python Fundamentals

✦Introduction to Python:

	Python is a high-level, interpreted, and easy-to-learn programming language. It was created by Guido van Rossum and released in 1991. Python is widely used for web development, software development, data science, artificial intelligence, and automation.

▸Python is called a:

    • Simple Language → Easy syntax similar to English.
    • High-Level Language → No need to manage hardware or memory directly.
    • Interpreted Language → Code runs line by line using an interpreter, so no compilation is needed before execution.

▸Features of Python:

    1. Simple and Easy to Learn:

    →Python has clean and readable syntax, making it beginner-friendly.

    2. High-Level Language:

    →Python is called a high-level language because it is easy for humans to understand and write.

    3. Interpreted Language:

    →Python executes code line by line, which makes debugging easier.

    4. Platform Independent:

    →Python programs can run on Windows, Linux, and Mac without major changes.

    5. Large Library Support:

    →Python provides many built-in libraries for different tasks like:

	Mathematics
	Web Development
	Data Analysis
	Machine Learning

    6. Open Source:

    →Python is free to use and available for everyone.

    7. Dynamically Typed:

    →No need to declare variable data types.

3. Core Python Concepts

✦ Understanding data types: integers, floats, strings, lists, tuples, dictionaries, sets.

▸ Data Types in Python

	→ Data types in Python define the type of value a variable can store.  
	→ Python provides different built-in data types to store numbers, text, and collections of data.

	→ Understanding data types is important because they help programmers perform operations correctly and efficiently.

▸ Common Data Types in Python:

1️.Integer (int)

	→ Integers are whole numbers without decimal points.  
	→ They can be positive, negative, or zero.
	• Example:
		age = 20
		marks = 95

2️.Float (float)

	→ Floats are numbers that contain decimal points.
	• Example:
		price = 99.50
		temperature = 36.7

3️.String (str)

	→ Strings are sequences of characters enclosed in single or double quotes.
	• Example:
		name = "Rahul"
		message = 'Hello Python'

4️.List (list)

	→ A list is an ordered and mutable collection of elements.
	→ Lists are created using square brackets [].
	• Example:
		numbers = [1, 2, 3, 4]
		colors = ["Red", "Blue", "Green"]

5️. Tuple (tuple)

	→ A tuple is an ordered and immutable collection of elements.
	→ Tuples are created using parentheses ().
	• Example:
		days = ("Monday", "Tuesday", "Wednesday")

6️. Dictionary (dict)

	→ A dictionary stores data in key-value pairs.
	→ Dictionaries are created using curly braces {}.
	• Example:
		student = {
    		"name": "Rahul",
    		"age": 20
		}

7️. Set (set)

	→ A set is an unordered collection of unique elements.
	→ Sets are created using curly braces {}.
	• Example:
		numbers = {1, 2, 3, 4}

✦ Python Operators: Arithmetic, Comparison, Logical, and Bitwise:

▸ Operators in Python are special symbols used to perform operations on variables and values.  
▸ Python provides different types of operators for mathematical calculations, comparisons, logical decisions, and bit-level operations.

1️.Arithmetic Operators:

	→ Arithmetic operators are used to perform mathematical operations such as addition, subtraction, multiplication, and division.
	
	• Operators:

		| Arithmetic Operator | Symbol | Description                      | Example |
		| ------------------- | ------ | -------------------------------- | ------- |
		| Addition            | +      | Adds two numbers                 | 10 + 5  |
		| Subtraction         | -      | Subtracts two numbers            | 10 - 5  |
		| Multiplication      | *      | Multiplies two numbers           | 10 * 5  |
		| Division            | /      | Divides two numbers              | 10 / 5  |
		| Modulus             | %      | Returns remainder                | 10 % 3  |
		| Exponent            | **     | Raises power                     | 2 ** 3  |
		| Floor Division      | //     | Returns quotient without decimal | 10 // 3 |

	• Example:

		a = 10
		b = 5
		print(a + b)
		print(a - b)
		print(a * b)

2️.Comparison Operators:

	→ Comparison operators are used to compare two values.
	→ They return either True or False.

	• Operators:

	| Operator | Description              | Example   |
	| -------- | ------------------------ | --------- |
	|   ==     | Equal to                 |  5 == 5   |
	|   !=     | Not equal to             |  5 != 3   |
	|   >      | Greater than             |  10 > 5   |
	|   <      | Less than                |  5 < 10   |
	|   >=     | Greater than or equal to |  10 >= 5  |
	|   <=     | Less than or equal to    |  5 <= 10  |

	• Example:
		x = 10
		y = 20
		print(x < y)
		print(x == y)

3️.Logical Operators:

	→ Logical operators are used to combine conditional statements.

	• Operators:

	| Operator | Description                                    | Example            |
	| -------- | ---------------------------------------------- | ------------------ |
	|   and    | Returns True if both conditions are true       |  x > 5 and y > 10  |
	|   or     | Returns True if at least one condition is true |  x > 5 or y < 10   |
	|   not    | Reverses the result                            |  not(x > 5)        |

	• Example:
		x = 10
		y = 20
		print(x > 5 and y > 10)

4️.Bitwise Operators:	

	→ Bitwise operators perform operations on binary numbers (bits).

	• Operators:

		| Operator | Description | Example    |  
		| -------- | ----------- | ---------- | 
		|   &      | Bitwise AND |  5 & 3     |  
		|   ^      | Bitwise XOR |  5 ^ 3     |
		|   ~      | Bitwise NOT |  ~5        |    
		|   <<     | Left Shift  |  5 << 1    |
		|   >>     | Right Shift |  5 >> 1    |

	• Example:
		a = 5
		b = 3
		print(a & b)
		print(a | b)

▸ Loops are used to execute a block of code repeatedly until a condition is satisfied.
▸ Instead of writing the same code many times, loops help automate repetitive tasks.

▸ Working of Loops

A loop follows these steps:

	1.Start the loop
	2.Check the condition
	3.Execute the code inside the loop
	4.Repeat the process
	5.Stop when the condition becomes False

▸ Types of Loops in Python
	Python has two main loops:
		for loop
		while loop

	1. Working of for Loop:

	▸ A for loop works by taking items one by one from a sequence like:
		• range
		• list
		• string
		• tuple
	• Example:
		for i in range(1, 6):
    		print(i)

	• Step-by-Step Working
	Step 1:
		range(1, 6) creates numbers:
		1, 2, 3, 4, 5
	Step 2:
		Variable i takes the first value → 1
		print(1)
	Step 3:
		i takes next value → 2
		print(2)
	Step 4:
		This process repeats until 5
	Step 5:
		After all values are used, loop stops automatically.

	• Output:
		1
		2
		3
		4
		5

	2. Working of while Loop:

	▸ A while loop works using a condition.
	▸ If condition is True → loop runs
	▸ If condition becomes False → loop stops
	• Example:
		i = 1
		while i <= 5:
    		print(i)
    		i += 1

	• Step-by-Step Working
	Step 1:
		i = 1
	Step 2:
		Condition checked:
		1 <= 5
		True → loop runs
	Step 3:
		Prints 1
	Step 4:
		i += 1
	Now:
		i = 2
	Step 5:
		Condition checked again
		This process repeats until:
		i = 6
	Now:
		6 <= 5
		False → loop stops

	• Output:
		1
		2
		3
		4
		5

8. Control Statements (Break, Continue, Pass):

✦ Understanding the role of break, continue, and pass in Python loops:

▸ In Python loops, break, continue, and pass are control statements used to change the normal flow of a loop.

	1. break Statement:

	→ The break statement is used to stop the loop immediately.
	→ When Python finds break, it exits the loop completely.

	• Syntax:
		for variable in sequence:
    		if condition:
        		break
	• Example:
		for i in range(1, 6):
    		if i == 4:
        		break
    		print(i)
	• Output:
		1
		2
		3
	• Explanation:
		→ Loop starts from 1
		→ When i becomes 4, break executes
		→ Loop stops immediately
		→ Number 4 and after are not printed

	2. continue Statement:

	→ The continue statement skips the current iteration and moves to the next iteration of the loop.

	• Syntax:
		for variable in sequence:
    		if condition:
        		continue
	• Example:
		for i in range(1, 6):
    		if i == 3:
        		continue
    		print(i)
	• Output:
		1
		2
		4
		5
	• Explanation:
		→ When i becomes 3, continue runs
		→ Python skips print(i) for that iteration
		→ Loop continues with the next value

	3. pass Statement:

		→ The pass statement does nothing.
		→ It is used as a placeholder when code is required syntactically but you do not want to write anything yet.

	• Syntax:
		for variable in sequence:
    		pass
	• Example:
		for i in range(1, 6):
    		if i == 3:
        		pass
    		print(i)
	• Output:
		1
		2
		3
		4
		5
	• Explanation:
		→ pass does not affect the loop
		→ Program continues normally
		→ Mainly used for future code planning
